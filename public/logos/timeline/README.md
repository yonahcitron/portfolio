# Timeline logos

Official artwork retrieved on 1 October 2026 and hosted locally so the timeline does not depend on third-party image requests.

- `cambridge.svg`: the unmodified shield paths from the [University of Cambridge website logo](https://www.cam.ac.uk/themes/custom/fresh/images/interface/cambridge_university2.svg), with the wordmark removed and the viewBox fitted to the shield.
- `kubrick.svg`: the complete inline vector logo from the [Kubrick website header](https://kubrickgroup.com/), displayed with padding so the wordmark and dots remain fully visible.
- `shell.svg`: the vector [Shell pecten icon](https://www.shell.com/etc.clientlibs/amidala/clientlibs/theme-base/resources/favicon/favicon.svg).
- `imperial.svg`: the vector [Imperial College London brand icon](https://www.imperial.ac.uk/assets/website/images/favicon/favicon.svg).
- `prax.webp`: the Prax logo supplied by Yonah, resized from the original 2000 × 2000 JPEG to a 180 × 180 WebP for the timeline badge. The complete image and original proportions are preserved.

The artwork retains each organisation's original colours and proportions.
